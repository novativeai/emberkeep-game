Generated by scripts/make-face-frames.py

Frame 0 is the rig's own head layer, copied verbatim: calibrate-faces.mjs
derives this set's scale and origin from it and proves them against that
same head, so the mapping is exact by construction.

The other drawings are single-image EDITS of that head (artgen.py edit,
Nano Banana 2), de-keyed off #00FF00 and registered back onto the head's
canvas by content-width scale + top-band (horn) centroid — the same maths
calibrate-faces uses, which is immune to the eye and jaw changes themselves.
The last frame is a byte-dup of the second: the half state plays once on the
way down and once on the way back up.

Exact per-frame timing is in frames.json. Sources and the reference plate
are in assets/raw/dragons/moonwhisker/faces/young/ (workspace only).
